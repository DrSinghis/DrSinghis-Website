# Dr. Singh's website (React + Vite)

A responsive first-pass landing page inspired by the approved visual mockup.

## Run locally
1. Install Node.js (LTS).
2. In this folder run:
   ```bash
   npm install
   npm run dev
   ```
3. Open the local URL printed by Vite.

## Build
```bash
npm run build
npm run preview
```

## Before publishing
- Verify phone, email, address, and company claims.
- Replace ingredient descriptions and benefit copy with approved, compliant product wording.
- Add remaining product data and product detail pages when ready.
- The generated hero product image is in `src/assets/refit-forte.png`.
